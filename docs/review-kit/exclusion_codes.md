# Exclusion reason codes (use exactly one per excluded report)

| Code | Reason |
|---|---|
| E1 | Not about land-border crossing, border posts or cross-border journeys |
| E2 | Does not study information needs, sources, preparation, awareness or difficulties (RQ1 to RQ5) |
| E3 | Not empirical (opinion, conceptual, system proposal without evaluation, legal text) |
| E4 | Review or scoping review (kept as background only) |
| E5 | Airport or seaport setting only |
| E6 | Outside 2010 to 2026, or not in English |
| E7 | Duplicate publication of the same study |
| E8 | Full text not available (report as "not retrieved", not as an exclusion) |

Population groups (traders, drivers, migrants, travellers, officials) are all **eligible** if the other criteria are met. Label each included study by population group.
